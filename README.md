SecureBank is a simple core Java-based banking application designed to manage basic account operations.
It allows users to create accounts with essential details like name, account number, and initial balance.
The application supports deposit, withdrawal, and balance inquiry functions.
Each transaction updates the account balance securely in real time.
Object-Oriented Programming principles such as encapsulation and inheritance are applied.
User input is handled using the Java Scanner class for a command-line interface.
Data validation ensures only correct and safe input is processed.
All account-related logic is implemented using custom classes in pure Core Java.
Security features include restricted access to private data using getters and setters.
